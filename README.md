# muse-student-skills
Muse（缪斯）是面向学生的个人学习管家，集成 16 个可协作的 Agent Skills。老师在群里改了几次截止时间？Muse 能回查原话、核对最新日期，把通知变成有出处、有截止时间的待办。  支持从 Windows 微信导出聊天、群成员和附件，离线转写语音，将文档、表格和聊天档案整理成可追溯的资料。可汇总重点消息、还原事项变更、梳理群聊分工、沉淀群聊知识，也能分析双向互动并给出沟通建议。  会话任务调度把多方消息汇成行动清单，联动课表、天气提醒、每日简报、截止提醒和考试复习计划。学业体检覆盖作业、笔记、复习计划和论文引用。还可生成学习海报、查找重复附件，以及诊断 Skill 的路径和依赖问题。
