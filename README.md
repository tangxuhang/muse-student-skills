# muse-student-skills
Muse（缪斯）是面向学生的个人学习管家，集成 16 个可协作的 Agent Skills。老师在群里改了几次截止时间？Muse 能回查原话、核对最新日期，把通知变成有出处、有截止时间的待办。  支持从 Windows 微信导出聊天、群成员和附件，离线转写语音，将文档、表格和聊天档案整理成可追溯的资料。可汇总重点消息、还原事项变更、梳理群聊分工、沉淀群聊知识，也能分析双向互动并给出沟通建议。  会话任务调度把多方消息汇成行动清单，联动课表、天气提醒、每日简报、截止提醒和考试复习计划。学业体检覆盖作业、笔记、复习计划和论文引用。还可生成学习海报、查找重复附件，以及诊断 Skill 的路径和依赖问题。
# Muse（缪斯）3.0.2 · 个人学习管家

Muse 把散落在聊天、课表和文档里的信息变成有出处的行动安排。老师发了新通知、作业临时改期或团队调整分工时，可以回到原消息核对，再更新待办、复习计划和每日简报。

## 16 个 Skill 功能索引

| 模块 | Skill | 提供什么 | 能得到什么 |
| --- | --- | --- | --- |
| 资料接入 | **微信记录导出** `wechat-local-data-export` | 本人已登录的 Windows 微信、指定会话和时间范围 | 本机可读的聊天记录和附件，可按类型或关键词筛选。聊天导出为 HTML、TXT，群成员名单导出为 Excel，可选离线语音转写 |
| 资料接入 | **多格式资料转写** `normalize-materials` | 聊天档案、文档或表格 | 带来源定位的 Markdown 或 JSON。可供阅读、搜索和后续任务提取 |
| 会话理解 | **重点信息汇总** `chat-attention-brief` | 一段时间内的群聊、私聊或通知 | 按重要程度整理的简报，标明哪些需要先看，哪些已有后续变更 |
| 会话理解 | **事项溯源** `chat-event-replay` | 一个具体事项和相关聊天记录 | 从提议、确认到改期、取消或完成的时间线，附可回查的原消息 |
| 会话理解 | **群聊分工图** `group-collaboration-map` | 群成员名单或群聊档案 | 负责人、角色、交接关系及待核实事项 |
| 会话理解 | **群聊知识整理** `chat-knowledge-curator` | 群里的问答、规则、经验和决定 | 可复用的 FAQ、操作流程和关键结论，保留出处 |
| 会话理解 | **双方关系分析** `social-relation-radar` | 指定对象的聊天档案及可核实的共同群聊 | 按时间段分析双向互动，给出行为证据和对应消息 |
| 会话理解 | **沟通参谋** `relationship-advisor` | 对话片段、沟通目标和个人偏好 | 对不同解读的分析、可直接使用的回复建议和后续沟通选项 |
| 学习与计划 | **会话任务调度** `wechat-skill-coordinator` | 目标及已有聊天或资料 | 选择对应 Skill，按会话组织复核和原话回查，汇总为个人计划 |
| 学习与计划 | **行动清单** `extract-action-items` | 已核对的通知、承诺和回执 | 带负责人、截止时间、来源和状态的待办，标出改期与待确认项 |
| 学习与计划 | **校园管家** `student-muse` | 课表、任务、重要通知和可选的城市配置 | 课表导入、每日简报、截止提醒和天气提示 |
| 学习与计划 | **考试复习助手** `student-exam-planner` | 考试日期、范围和已有安排 | 考试信息汇总、复习重点与按日计划 |
| 学习与计划 | **学业体检** `study-review` | 作业、笔记、复习计划或论文 | 提交前自查、查漏补缺和引用规范检查 |
| 产出与维护 | **海报设计** `daily-task-poster` | 已确认的待办或计划 | 可导出为 PNG 或 JPG 的任务海报，支持多种版式 |
| 产出与维护 | **冗余文件清理** `chat-attachment-tracker` | 指定附件目录和可选的聊天线索 | 重复文件清单、版本线索和拟保留路径。确认后可清理副本 |
| 产出与维护 | **Skills 修理所** `skill-workflow-adapter` | 运行日志、本机环境或失败场景 | 路径、依赖和输入格式的诊断，附复测建议和可回退的本机配置 |

## 用样例体验一次

下载并解压 `Muse_3.0.1.zip`，用支持 Agent Skills 的工具打开「提交」文件夹作为工作区。可以直接对 Agent 说：

> 读取 `.agents/examples/campus-notices.md`，找出实验二最终截止时间、改期原话和我还需要做的事，再整理成行动清单。

样例里的截止时间从 **11 月 17 日 17:00** 延至 **18:30**，提交平台保持不变。「资料领取回执」在后续消息里已有提交记录。通过这个例子可以核对 Muse 是否找对了改期证据，并正确区分待办和已完成事项。

## 下载、运行与目录

- 从 **Assets** 下载 `Muse_3.0.1.zip`。[最新版发布页](https://github.com/tangxuhang/muse-student-skills/releases/latest)
- `.agents/skills/<Skill ID>/SKILL.md` 是每个 Skill 的入口说明。对应目录还包含参考资料、脚本或其他资源。
- `.agents/scripts/` 存放共享脚本，`.agents/schemas/` 存放数据格式，`.agents/examples/` 提供虚构样例，`.agents/README.md` 提供运行命令和依赖说明。
- 通用脚本需要 Python 3.10 或更新版本。微信本机导出需要 Windows x64、Python 3.13 和本人已登录的微信。定时提醒取决于使用工具是否支持调度。
